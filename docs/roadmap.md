## 1. Тиждень 3: Старт та Auth

### HTML + CSS (Фронт)
* Верстка сторінок Login/Register
* Базовий Layout сайту

### Node.js (Бекенд)
* Налаштування Node.js (Express)
* Ендпоінти `/auth/register` та `/auth/login`
* Генерація JWT

### PostgreSQL (БД)
* Ініціалізація PostgreSQL
* Створення таблиць `users`, `roles`
* Скрипти початкових міграцій

## 2. Тиждень 4: Дерево й сторінки

### HTML + CSS (Фронт)
* Верстка бічного меню (Sidebar)
* Модальні вікна створення сторінки
* Список регламентів

### Node.js (Бекенд)
* CRUD-ендпоінти для `/pages`
* Middleware перевірки ролей (RBAC)
* Обробка ієрархії сторінок

### PostgreSQL (БД)
* Таблиця `pages` (`parent_id` для дерева)
* Зовнішні ключі та зв'язки
* Налаштування індексів пошуку

## 3. Тиждень 5: Редактор і контент

### HTML + CSS (Фронт)
* Стилізація робочої області
* Блоки форматування, фігури
* Вставка картинок і посилань

### Node.js (Бекенд)
* Ендпоінт збереження вмісту сторінки
* Завантаження файлів/зображень

### PostgreSQL (БД)
* Схема збереження вмісту (JSON/Text)

## 4. Тиждень 6: Таблиці й реліз

### HTML + CSS (Фронт)
* Верстка вбудованих таблиць обліку
